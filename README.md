# AdventureWorks Internet Sales - Exploratory Data Analysis

A comprehensive **Exploratory Data Analysis (EDA)** project built using the Microsoft AdventureWorks Internet Sales dataset. This notebook demonstrates the complete data analysis workflow—from loading and cleaning data to generating business insights through statistical analysis and visualizations.

---

## Project Overview

This project analyzes internet sales transactions to identify sales trends, customer behavior, product performance, and business opportunities using Python's data analysis ecosystem.

The analysis simulates a real-world business intelligence workflow commonly performed by Data Analysts.

---

## Dataset

The project uses the **AdventureWorks** sample data warehouse, which contains historical sales data for an online bicycle and accessories retailer.

### Tables Used

- FactInternetSales
- DimCustomer
- DimDate
- DimProduct
- SalesBudget
